# Combined Shortcut Card (VS Code + Floyd)

Use this as your desk card for the next few weeks.

---

## VS Code (macOS) — Developer Core

### Open, Find, Navigate

| Shortcut | Purpose |
|---|---|
| `Cmd+P` | Quick-open any file |
| `Cmd+Shift+P` | Run any command |
| `Cmd+F` | Find in current file |
| `Cmd+Shift+F` | Find across project |
| `F12` | Go to definition |
| `Shift+F12` | Find references |
| `F2` | Rename symbol safely |
| `Ctrl+G` | Jump to line |
| `Ctrl+-` / `Ctrl+Shift+-` | Back / Forward navigation |

### Edit Fast

| Shortcut | Purpose |
|---|---|
| `Cmd+D` | Select next match |
| `Cmd+Shift+L` | Select all matches |
| `Option+Click` | Add cursor |
| `Option+Up/Down` | Move line |
| `Shift+Option+Up/Down` | Duplicate line |
| `Cmd+/` | Toggle comment |
| `Shift+Option+F` | Format document |

### Terminal + Git + Debug

| Shortcut | Purpose |
|---|---|
| `Cmd+\`` | Toggle terminal |
| `Ctrl+Shift+\`` | New terminal |
| `Ctrl+Shift+G` | Source control panel |
| `F5` | Start/continue debug |
| `Shift+F5` | Stop debug |
| `F9` | Toggle breakpoint |
| `F10` / `F11` | Step over / step into |

---

## Floyd — Daily Core

### Global

| Shortcut | Purpose |
|---|---|
| `Ctrl+G` | Show help / shortcuts |
| `Ctrl+P` | Open command palette |
| `Ctrl+L` or `Ctrl+M` | Switch model |
| `Ctrl+S` | Open sessions manager |
| `Ctrl+T` | Open embedded terminal |
| `Tab` | Cycle panel focus |

### Prompt Editor

| Shortcut | Purpose |
|---|---|
| `Enter` | Send message |
| `Shift+Enter` or `Ctrl+J` | New line |
| `` ` `` or `Ctrl+Y` or `Ctrl+]` | Accept AI suggestion |
| `Ctrl+E` | Request AI suggestion now |
| `/` | Add file / command action |
| `@` | Mention file |
| `Up/Down` | Prompt history |
| `Esc` | Cancel current action |

If your terminal swallows backtick, use `Ctrl+Y` first; `Ctrl+]` is a second fallback.

### Chat Navigation

| Shortcut | Purpose |
|---|---|
| `j` / `k` | Scroll down/up |
| `d` / `u` | Half-page down/up |
| `f` / `b` | Full page down/up |
| `g` / `G` | Top / Bottom |
| `Space` | Expand/collapse message |
| `c` / `y` | Copy selection |

---

## One-Card Daily Drill (10 minutes)

1. In VS Code: open file with `Cmd+P`, jump with `F12`, return with `Ctrl+-`.
2. In VS Code: do one rename with `F2` and one multi-edit with `Cmd+D`.
3. In Floyd: send one prompt with `Enter`, then use `Shift+Enter` for multiline.
4. In Floyd: navigate with `j/k`, then jump with `g/G`.
5. In both tools: use command palettes (`Cmd+Shift+P` in VS Code, `Ctrl+P` in Floyd).
