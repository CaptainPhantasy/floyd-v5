## II. ARCHITECTURAL DECISION: ASYMMETRIC BYZANTINE QUORUM (ABQ)

### Why Not Standard PBFT/Tendermint?

| Protocol | Latency | Issue for Safety Systems |
|----------|---------|--------------------------|
| PBFT | 2-3 RTT (~150ms) | Exceeds 100ms budget |
| Tendermint | 2 RTT (~100ms) | Symmetric quorum treats HAZARD and CLEAR equally |
| HotStuff | 3 phases | Linear but still 3 round trips |
| **ABQ (proposed)** | **1 RTT + crypto** | **Asymmetric: CLEAR needs supermajority, HAZARD needs minority** |

### Deterministic Rationale

The critical insight: **safety shutdown is asymmetric**. 

- **False positive** (shutdown when safe): Operational cost, recoverable
- **False negative** (clear when hazardous): **Catastrophic, non-recoverable**

Therefore: Apply **asymmetric Byzantine quorum thresholds**:
- `ALL_CLEAR` requires **2f+1 honest confirmations** (supermajority)
- `HAZARD` triggers on **f+1 independent reports** (minority can force safety)

                clear: 0,

        let mut clear_weight: u32 = 0;

                SensorState::Uncertain => {

                    hazard_weight += weight / 2;
                }

        let node_count = round.readings.len() as u32;

                total_weight,

                clear_weight,
                total_weight,

            // This is the conservative choice for safety-critical systems
            Ok(ConsensusDecision::UncertainShutdown {
                hazard: hazard_weight,
                clear: clear_weight,
            })
        }

    }

## VI. FORMAL SAFETY GUARANTEE

**Theorem:** With `n` nodes where `f ≤ ⌊(n-1)/3⌋` are Byzantine, ABQ-Consensus guarantees:

1. **Safety:** If any honest node detects hazard, system reaches `SafetyShutdown`
2. **Liveness:** If all honest nodes report clear, system reaches `AllClear`  
3. **Byzantine Tolerance:** `f` malicious nodes cannot force `AllClear` when hazard exists

**Proof Sketch:**
- Hazard threshold = `f+1` honest nodes
- Clear threshold = `2f+1` nodes
- Byzantine coalition size ≤ `f`
- To block shutdown: Byzantine must prevent `f+1` hazard reports
- But honest hazard reporters ≥ `f+1` (by assumption of true hazard)
- Therefore shutdown cannot be blocked by ≤`f` Byzantine nodes ∎
