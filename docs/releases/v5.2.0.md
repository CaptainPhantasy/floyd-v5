# Release v5.2.0 (SOTA Enterprise Integration)

This release stabilizes the underlying reasoning architecture, un-bridges latent UI features into full interactivity, and introduces a 6-tool specialized split for Floyd and SuperFloyd identities.

## Key Changes
- **Core Splitting:** Enforced `FLOYD` as the general operational agent and `SUPERFLOYD` as the coding/architect master.
- **SOTA Tool Expansion:** 6 brand new tools implemented natively (bypassing MCP bounds for sheer speed).
  - *Floyd tools*: `project_map`, `manage_scratchpad`, `list_symbols`.
  - *SuperFloyd tools*: `apply_patch`, `smart_replace`, `get_active_diff`.
- **System Determinism:** Deduplicated the conflicting SOTA instructions spanning the 95 extensible `.md` agents. `<think>` block logic is now a global, unwavering standard inside the Go `.tpl` templates.
- **Latent Features Wired:**
  - `web_search` natively exposed to the active tool cycle.
  - *Config Audit* and *Plugins Library* successfully hooked into `ui.go` and `commands.go` message buses natively via Bubbletea.
  - The *Auto-Stabilize Diagnostic Bus* evaluates prompt size and intercepts it mid-stream, flashing a UI warning rather than terminal degradation.

For a comprehensive breakdown on using these features, check out [QUICKSTART_v5.2.md](../QUICKSTART_v5.2.md).
