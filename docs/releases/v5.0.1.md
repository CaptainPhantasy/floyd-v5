# Floyd v5.0.1 - The "Friction-Free" Production Release

**Date:** 2026-03-14
**Version:** v5.0.1
**Engine:** Deterministic v5.0.1 (Floyd / SuperFloyd)

## Summary

Floyd v5.0.1 is a major production-grade overhaul focused on eliminating workflow friction and establishing a deterministic runtime baseline. This release introduces the **Twin-Engine** system, a unified extensibility library, and a multiplexed persistent terminal.

---

## Core Features

### 1. Twin-Engine Harness (Floyd & SuperFloyd)
Floyd now detects its binary identity at runtime to load specialized deterministic prompts:
- **Floyd**: Your multipurpose technical co-pilot. Optimized for orchestration, documentation, and system analysis.
- **SuperFloyd**: An elite SOTA Software Architect. Optimized for high-output coding, surgical refactoring, and complex architectural integrity.

### 2. Multiplexed Persistent Terminal
The terminal is no longer a hidden utility. It is now a first-class workspace component:
- **Persistence**: Sessions remain active in the background when the panel is hidden.
- **Multiplexing**: Support for multiple concurrent shells.
- **Auto-Transition**: Selecting "Open Terminal" while on the landing page automatically switches you to the chat view.
- **Power User Access**: Terminal bypasses all agent-level restrictions for direct manual control.

### 3. Unified Extensibility Library (90+ Agents, 20+ Skills)
We have formalized the extensibility ecosystem:
- **Categorization**: 90 production agents and 20 core skills are now organized into 13 domains (Architecture, Security, Testing, etc.).
- **Frictionless UI**: A new category-based tab system with `0..9` shortcuts and `Alt+1..6` domain jumps.
- **Search Everywhere**: Search all 90 agents and 20 skills directly within the Command Palette.
- **Expansion (`e` key)**: Peek at full system prompts and skill instructions before selection.

### 4. Deterministic Reasoning (Thinking Mode)
Full integration with Z AI / Hyper "Thinking Mode":
- **Thinking Blocks**: The harness now explicitly utilizes `<think>` tags for complex architectural planning.
- **Structured Extraction**: Reasoning tokens are streamed and stored separately, preventing "reasoning leakage" into the conversation history.

## Technical Refactors

- **Filesystem Optimization**: Refactored the "Context Singularity" logic to bypass massive system directories and added deterministic timeouts to prevent initialization hangs.
- **Code Integrity**: Implemented "Clean & Sign" protocols to ensure binaries are trusted by the macOS Code Integrity Guard (CIG).
- **Summarization Alignment**: Aligned history truncation with the "Crush" standard to maintain context integrity at high token counts.
